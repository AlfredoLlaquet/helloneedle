# Contributing to Hello Needle

Start with the [project record](AGENTS.md) for module boundaries, search and preview behavior, native GUI verification, packaging, and open questions. Update it in the same change as the affected behavior. The [README](README.md) contains the user-facing guide and build instructions. Each contribution retains its applicable authorship and licensing notices. [License and credits](NOTICE.md)

Hello Needle development takes place in [AlfredoLlaquet/helloneedle](https://github.com/AlfredoLlaquet/helloneedle). Direct proposed changes for Hello Needle to this repository. The retained GTK application is the Clapgrep reference implementation.
