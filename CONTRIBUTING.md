# Contributing to Hello Needle

Start with the [project record](AGENTS.md) for the source map, document formats, verification procedures, and current decisions. Update the record in the same change as the affected behavior or maintenance instructions. The [README](README.md) contains the commands for building and testing the current FreeBSD reference. Each contribution retains its applicable authorship and licensing notices. [License and credits](NOTICE.md)

Hello Needle development takes place in [AlfredoLlaquet/helloneedle](https://github.com/AlfredoLlaquet/helloneedle). Direct proposed changes for Hello Needle to this repository. The retained GTK application is the Clapgrep reference implementation, and its original project and translators are identified in the attribution notice.
