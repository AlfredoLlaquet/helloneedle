Hello Needle for macOS

Open the Hello Needle disk image in Finder. Drag Hello Needle to the Applications shortcut. Eject the disk image, then open Hello Needle from Applications. The keyboard equivalent is to select Hello Needle, press Command+C, press Shift+Command+A to open Applications, and press Command+V.

The Universal disk image includes Intel and Apple Silicon code. The architecture-specific disk images are marked x86_64 (Intel) or arm64 (Apple Silicon). A per-architecture build's release notes give its tested macOS version. The installed application contains Qt, the Cocoa platform and macOS style plugins, Spanish translations, the search worker, and local PDF and Word readers with their runtime libraries and data.

The app carries an ad hoc code signature. It has no Developer ID signature or Apple notarization. Download it from the official release. If the Mac's security policy permits it, macOS can offer Open Anyway in System Settings > Privacy & Security after the first attempt to open it.

To update, quit Hello Needle and replace its copy in Applications. To uninstall, quit the app and move it to the Trash. Documents and user preferences are stored separately.

The disk's LICENSE is Hello Needle's GNU General Public License. Help > Licenses displays the installed project and component notices offline. The full texts, the package inventory and the build's source revision are in Hello Needle.app/Contents/Resources/licenses. For a Universal build the architectures/arm64 and architectures/x86_64 subdirectories contain the corresponding native dependency records. The release provides the matching project source and native runtime source archives alongside the disk image.
