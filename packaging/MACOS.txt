Hello Needle for macOS

Choose the archive for the Mac's operating system and processor.

    macOS 26 Tahoe, Apple Silicon     arm64
    macOS 15 Sequoia, Intel           x86_64

Both builds use MacPorts in its standard /opt/local location. If the
Xcode Command Line Tools are missing, install them from Terminal.

    xcode-select --install

Download the MacPorts installer for Tahoe or Sequoia to match the
installed system. https://www.macports.org/install.php

Install the four runtime packages from Terminal.

    sudo /opt/local/bin/port install qt6-qtbase qt6-qttranslations poppler antiword

Extract the ZIP, move Hello Needle.app to Applications, and open it in
Finder. Qt provides the interface and its standard translations. Poppler
handles PDFs. The included worker reads Word 97–2003 documents directly,
and antiword handles earlier Word formats.

This build carries an ad hoc code signature. Gatekeeper can require
approval or block launch according to the Mac's security policy.

To update, quit Hello Needle and replace the app. To remove it, delete
the app from Applications. MacPorts maintains the runtime packages.
The app's Contents/Resources/licenses folder holds the component notices,
installed package versions and source revision. The Actions run supplies
the matching source archive.
