Hello Needle for Windows x64

Install the current MSYS2 distribution from https://www.msys2.org/.
Open the MSYS2 UCRT64 terminal and install the runtime packages with

    pacman -Syu
    pacman -S --needed mingw-w64-ucrt-x86_64-{qt6-base,qt6-translations,poppler,antiword}

If pacman asks to close the terminal during an update, reopen UCRT64 and
complete the update before installing those four packages. The application
requires no compiler, Rust installation, or Python installation.

Use Extract All in Explorer and keep the extracted files together.
Double-click Hello Needle.exe at the top of the extracted folder. It finds
the standard C:\msys64\ucrt64 installation. For a custom installation,
set the Windows environment variable HELLONEEDLE_UCRT64 to its full ucrt64
folder, or start the launcher from the corresponding UCRT64 terminal.

The bin folder contains the Qt application and search worker. Poppler
provides PDF extraction and rendering. Antiword reads legacy .doc files.
Qt and these converters receive updates through MSYS2. This archive
contains x64 binaries. Windows 11 on Arm runs them through x64 emulation.

To update Hello Needle, quit the app and extract the replacement archive
to a fresh folder. To remove it, delete the extracted folder. Installed
licenses, package versions and the source revision are in
share\doc\helloneedle. The Actions run supplies a matching source archive.
