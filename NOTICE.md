## Hello Needle desktop and worker

The new application code, project documentation, original icon, and project-authored test fixtures are distributed under GPL-3.0-or-later. Alfredo Llaquet-Alsina selected the astonished cow’s face for the application icon. ChatGPT generated the original artwork for Hello Needle. The desktop and platform icons are renditions of the same transparent master. [Cow icon](desktop/qt/helloneedle.png) The retained Clapgrep search and traversal lineage is credited in the new Rust worker. The binary Word test fixture was exported by LibreOffice from the original text distributed beside it. [Worker and dependencies](bridge/) · [Qt desktop](desktop/qt/) · [Test fixture source](tests/desktop/fixtures/sample.txt)

The desktop dynamically uses the platform’s Qt 6 Core, Gui and Widgets libraries. Qt Test is a test dependency. The separately installed Poppler utilities provide PDF text and page rendering. The Rust worker reads the main story of Word 97–2003 documents using the MIT-licensed cfb crate. Antiword and its character maps enable older Word variants. All of these components retain their own authorship and terms. MacPorts supplies the Qt libraries and translations, Poppler, and antiword for the Apple Silicon and Intel macOS packages. Each package includes a record of its runtime versions and their sources. [Native component inventory](cmake/NATIVE-COMPONENTS.md.in) · [Qt licensing](https://doc.qt.io/qt-6/licensing.html) · [Poppler](https://poppler.freedesktop.org/) · [Antiword](https://sources.debian.org/src/antiword/)

The worker incorporates the Rust crates identified by its independent lockfile. The distribution script preserves each crate’s declared license and available original license files, including notices for separately licensed data. Four specific archives omit a standalone full license document. For those versions the package includes the upstream manifest or source header and the applicable full license text. The Apache License 2.0 option is used for fxhash 0.2.1, mac 0.1.1, and match_token 0.35.0. Selectors 0.31.0 is distributed under MPL 2.0. Their complete sources are included in the corresponding source archive. [Locked dependency graph](bridge/Cargo.lock) · [Distribution script](tools/source_bundle.py) · [Apache License 2.0](LICENSES/rust-dependencies/Apache-2.0.txt) · [Mozilla Public License 2.0](LICENSES/rust-dependencies/MPL-2.0.txt)

## Source and binary distributions

The repository contains the original GPL text, applicable notices for the material above, build files, and Cargo’s dependency lockfile. Packages fetched separately by Cargo or an operating-system package manager retain their own licenses. The inherited FreeBSD reference installs the GPL text, this notice, and the component notices under the configured data directory at `doc/clapgrep`.

Each Hello Needle native binary artifact accompanies the corresponding source for its exact revision, including the build and installation scripts, vendored Rust dependencies and offline Cargo configuration. Each staged package includes the applicable notices and a native-component inventory. The installed About dialog makes the texts available offline.
