## Source and binary distributions

The repository contains the original GPL text, applicable notices for the material above, build files, and Cargo’s dependency lockfile. Packages fetched separately by Cargo or an operating-system package manager retain their own licenses. The inherited FreeBSD reference installs the GPL text, this notice, and the component notices under the configured data directory at `doc/clapgrep`.

A Hello Needle binary distribution must identify its exact source revision and carry the applicable notices for the actual bundled components. The project will provide complete corresponding source, including required library sources, modifications, and build and installation scripts, alongside those binaries. The artifact-specific inventory and source instructions belong with each release. [Project distribution procedure](https://github.com/AlfredoLlaquet/helloneedle/blob/main/AGENTS.md#credits-licenses-and-release-engineering)
