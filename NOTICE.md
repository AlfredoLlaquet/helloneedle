## Hello Needle desktop and worker

The new application code, project documentation, original icon, and project-authored test fixtures are distributed under GPL-3.0-or-later. Alfredo Llaquet-Alsina selected the astonished cow’s face for the application icon. ChatGPT generated the original artwork for Hello Needle. The desktop and platform icons are renditions of the same transparent master. [Cow icon](desktop/qt/helloneedle.png) The retained Clapgrep search and traversal lineage is credited in the new Rust worker. The binary Word test fixture was exported by LibreOffice from the original text distributed beside it. [Worker and dependencies](bridge/) · [Qt desktop](desktop/qt/) · [Test fixture source](tests/desktop/fixtures/sample.txt)

The desktop dynamically loads Qt 6 Core, Gui, Widgets, SVG and native platform plugins. Qt Test supports the test suite. SQLite stores search results and file diagnostics. Poppler provides PDF text extraction and page rendering. The Rust worker reads the main story of Word 97–2003 documents using the MIT-licensed cfb crate. Antiword and its character maps enable older Word variants. The Qt libraries remain individually replaceable. Third-party code, fonts and mapping data retain the copyrights and license terms supplied by their authors. [Native components](cmake/NATIVE-COMPONENTS.md.in) · [Qt licensing](https://doc.qt.io/qt-6/licensing.html) · [Poppler](https://poppler.freedesktop.org/) · [Antiword](https://sources.debian.org/src/antiword/)

The worker incorporates the Rust crates identified by its independent lockfile. The distribution script preserves each crate’s declared license and available original license files, including notices for separately licensed data. Four specific archives omit a standalone full license document. For those versions the package includes the upstream manifest or source header and the applicable full license text. The Apache License 2.0 option is used for fxhash 0.2.1, mac 0.1.1, and match_token 0.35.0. Selectors 0.31.0 is distributed under MPL 2.0. Their complete sources are included in the corresponding source archive. ## Source and binary distributions

The repository contains the original GPL text, applicable notices for the material above, build files, and Cargo’s dependency lockfile. Packages fetched separately by Cargo or an operating-system package manager retain their own licenses. The inherited FreeBSD reference installs the GPL text, this notice, and the component notices under the configured data directory at `doc/clapgrep`.

Each Hello Needle native binary artifact accompanies the corresponding source for its exact revision, including the build and installation scripts, vendored Rust dependencies and offline Cargo configuration. Each staged package includes the applicable notices and a native-component inventory. The installed About dialog makes the texts available offline. [Project distribution procedure](Hello%20Needle.txt)

For a Project MT FreeBSD 15.x development package, the successful Actions run records the tested commit, the SHA-256 digest and a link to its matching offline source archive. The pkg version includes the run and attempt numbers. The project record identifies the private documents used only for local verification by format. Their contents are excluded from source distributions, CI and native packages. [Development builds and matching sources](https://github.com/AlfredoLlaquet/helloneedle/actions/workflows/freebsd-package.yml?query=branch%3Adevelopment)

The standalone Windows and macOS installers also have a native runtime source companion. Its `RUNTIME-SOURCES.json` identifies each distributed runtime file, its package or local build, the applicable source archives, patches and build inputs. `SHA256SUMS` verifies the companion. The same component inventory is installed as `LICENSES/native/PACKAGES.json`. Each component’s notice index points to the original texts available offline. Download the native runtime sources alongside the installer and the Hello Needle project source. [Releases and sources](https://github.com/AlfredoLlaquet/helloneedle/releases) · [Collection and verification](tools/runtime_sources.py)

The Windows companion preserves MSYS2’s signed UCRT64 all-source packages, including the upstream inputs, PKGBUILDs and distribution patches. The macOS companion supplies MacPorts recipes, PortGroup checks, original distfiles and selected variants, plus the upstream archive, local modifications and build instructions for the bundled Poppler helpers. The project source contains both installers’ staging and signing recipes. Those recipes can assemble the application with replacement libraries for personal use. Windows system interfaces and Apple system frameworks remain available from their respective operating systems. [MSYS2 source archive](https://repo.msys2.org/mingw/sources/) · [MacPorts source tree](https://github.com/macports/macports-ports) · [GNU GPL distribution terms](https://www.gnu.org/licenses/gpl-3.0.html)
